## 0. 思考驱动原则（最重要，先读）

**这套流程的"思考链路"由主循环模型（最新 Claude，当前 Opus）实时驱动——不是跑一遍固定脚本。**

- 七阶段是**脚手架**，真正的工作是**反复迭代的模型推理**：每一步都要模型**实时判断 → 自我挑战 →
  挖最弱的那条腿（用新的工具调用取证）→ 诚实纠错 → 重判**。今天的质量（西班牙打穿辨析、比利时实证
  打脸、埃及让负修正、状态≠战意）全来自这些来回回合，**不是任何单个脚本/agent 一次产出的**。
- **工具/脚本/agent 只做三件支撑**，判断永远不烤进脚本：
  1. **取现有数据**：体彩子盘 / `bold_odds.json` / `bold-review.json`（历史账，bold-review 引擎已删不再产出）/ 快照（用当前 fetch 函数）。
  2. **采集外部信息**：WebSearch/WebFetch + `jczq-match-analyst` agent（模型主动调用拿新鲜事实）。
  3. **确定性算术**：组合赔率 × 命中 × 期望——**只为执行"禁嘴算"纪律**，不是替代判断。
- **模型用最新版**：主循环 + 派出的 agent 都跑最新/最强 Claude（agent frontmatter `model: opus`），
  因为每个中间环节都是 judgment-heavy，不能降智。
- **可被打断、可被质疑**：用户的每次追问（"为什么改主意""有没有优化空间"）都触发一轮新的
  实时校正——这是 feature，流程要为反复推敲留口子，而非一次性输出。

## 七阶段流程

### Phase 0 · 数据底座（沿用 SOP）
跑 `decision-am`（launchd 08:00 已自动，手动补跑见 CLAUDE.md SOP 步骤 1），读决策 store

### Phase 1 · 盘口与赔率底座（数据纪律的来源）
- **国际去水 fair**：读 `.nutmeg-data/jczq/daily/<date>/bold_odds.json`（1X2 + 大小球，已去水）。
- **体彩全玩法子盘**：`SportteryJczqCalculatorProvider().fetch()`（`nutmeg.services.jczq`）取
  `had/hhad/crs/ttg/hafu`。WAF 易 403/降级 → 优先用本会话已抓的缓存或 `sporttery_markets.json` 快照；
  **WAF 降级响应（vtoolsConfig-only / had 空）别覆盖好快照**。
- ⚠️ **数据纪律**：所有概率/edge/覆盖率**只来自此底座或脚本计算，禁嘴算**。组合赔率/命中率一律
  写进 Python 脚本算（确定性、可复现）。
- **日级盘面热度诊断（2026-07-07 起，只读不决策）**：`daily/<date>/day-regime.json`
  （decision-am 自动产，手动补 `decision-day-regime`）——当日热门均值/重热门数/均势数/
  欧-体 gap 警戒/期望进球均值。**只是攒样本的诊断数据，不得作为任何判读或票面理由**；
  日后若校准显示 regime 指标与冷门率相关，走 scoped 因子入词典（n<30 只攒不改模型）。

### Phase 2 · 逐场深研（`jczq-match-analyst` agent，每场一个，web）
每场并行派一个 agent，**实时检索**（赛事在知识截止后，严禁编造、要来源），返回：

> **反偏置约束已烤进 agent 定义文件**（`.claude/agents/jczq-match-analyst.md`，2026-07-06 起）：
> 低分叙事滤镜 / 疲劳牌高估 / fade 钱流教条 / 战意故事翻面 四条 + 淘汰赛 90' 口径 + 3 路让球陷阱。
> **不要在派发提示词里现场口传**——那是 6/04 大复盘批过的"决策不钉死"复发路径；
> 要改约束就改 agent 文件本体并同步本节。主循环自己判读时同样受这六条约束。
- 小组/积分/**出线情境**（must-win？已出线？弃赛轮换风险？）
- MD1 结果与表现（控球/射门/xG）
- 预计首发/阵型/**伤停**
- **战术对位**（尤其"破密集防守"能力——强队对低位铁桶常打不开）
- 爆点球员
- **状态 (condition)**：旅行距离/跨时区/赛程密度/备战/疲劳/伤病
- **战意 (fighting will)**：士气/动力/围城心态/政治/必胜压力
- 比分倾向

### Phase 3 · 实力排序 + 每场玩法判断（核心创作）
- 八队中立实力排序 + 本场实力 gap。
- 对每场**逐一判断五种玩法**（胜平负/让球/比分/总进球/半全场），用**换玩法逆转**原则选最优表达（见下）。
- **信心语义（2026-07-06 校准落库）**：conf4 已实证良好校准（15/18=83%）；**conf5 只许授予
  "90 分钟方向"判断**，"会晋级/实力碾压"不构成 conf5（唯一一次 conf5 = 087 阿根廷正是死在
  90' 1:1）。**淘汰赛"强弱悬殊 + 弱队铁桶画像"场次：正路判断信心硬顶 conf4**，并且必须
  同时产出让球双选对冲表达（087 当天 ¥10 让平+让负对冲赢了而 conf5 正路错了=认知在、
  输出规则没跟上，这条就是那个输出规则）。
- **意见票玩法门槛（同日落库）**：判读层已实证的能力是**方向**不是净胜球分布
  （had 意见票 2/2 vs hhad 3/9）。意见票**默认 had 押模态方向**；hhad 单关只在
  DC 矩阵显示**单一净胜模态 ≥35%** 时允许（"恰净胜 N"窄带玩法如 090 让平+2 属禁区）。
- **双轴表达（2026-07-07 用户定调落库：方向轴 × 进球轴）**：
  - **打穿共振三条件**：让胜(-1)/大胜类表达必须同时满足 ①正路 conf≥4、②去水 fair
    大 2.5 球 ≥55%、③DC 净胜≥2 概率 ≥40%；缺任一条退回正路或进球轴。机理：强判胜≠打穿，
    打穿=两轴共振（7/07 阿根廷 70% 强判但大小球抛硬币 → 让胜仅 44.8% vs 市场隐含 55.6%，
    正是"只看方向就上让胜"的陷阱样本）。
  - **方向抛硬币 → 换进球轴**：fair 最大方向 <45% 的场，判断密度在总进球模态带 + 模态比分
    （两轴近正交：方向=λ差、进球=λ和；门将伤/射手缺这类信息常对总进球比对胜负更干净）。
    进球轴表达=模态单点+小额（比分腿历史命中仅 6%），串关腿仍用高命中桶。

## 核心原则（今天沉淀的"思考链路"）

1. **状态 ≠ 战意，分开看**：condition（旅行/备战/疲劳）和 will（士气/围城心态/政治）**常方向相反**。
   - 实例：政治"伤了伊朗状态、却点燃战意（围城心态→铁桶更顽固）"；旅行"累了新西兰、鲜活了埃及"。
   - 铁桶防守的有效性**高度依赖集体意志**——所以战意比状态更决定铁桶能不能守住。
2. **换玩法逆转**：同一场不同玩法表达不同剧本，选**最贴模态剧本**的玩法：
   - 强队赢但小 → **胜平负胜**（窗口最宽）；强队净胜恰 1/2 → **让球平**；
   - 强队晚破铁桶 → **半全场 半平/全胜 (dh/da)**；低进球/铁桶 → **总进球小**；
   - 胜负是掷硬币（可能被逼平）→ 改赌**总进球**（更可预测）而非胜负。
3. **让球平是实证最准的高赔玩法**（≈15% 腿命中、命中的几乎全是让平）；
   **胜平负押冷门是 0/23 死亡陷阱**（大众的"爆冷梦"）。
4. **命中优先反转选腿**：腿越少越好；高赔区命中只有个位~10%，长期多输少赢。
5. **人性/盘口**：大众高估"大胜/打穿/大球/漂亮比分/弱队爆冷"→ value 在"小胜/小球/丑比分/让平"。
6. **每腿押模态、不押隔壁**；组合审核必查。
7. **诚实纠错**：挖弱腿、改判说清"什么变了"、别浅层 flip-flop。
8. **空仓永远合法**；高赔=高方差彩票区，娱乐预算小额（主推 ≤¥10、彩票 ≤¥5）。

## 失败教训（硬数据，必读——**注意每条属于哪一层**，别跨层错配）

### 引擎串票层（大胆/tiered 冷腿组合）
- **大胆/高赔串：整票命中 0/38（38 张全输）；大胆腿 29/205 ≈ 14%。** "3 条冷腿堆 100x+"必死。

- 腿级按玩法：**让球 15%（让平为主）> 比分 6%（命中是 1-1 闷平）> 胜平负冷门 0/23 > 总进球 0/5**。
- 引擎 v2 档位（5/25-7/05 补结后）：**A 2/17 回款 201/385、B 0/14、D 0/2、E 0/7**——B/D/E 纯方差实证，A 有微弱结构信号。
- 推论：高赔不是不能中，但要押"让平/闷平比分/晚破/小球"这些被大众低估的，**别堆冷腿、别押冷门正路**。

### 判读层（评判员 predictions/意见票，6/22-7/04 记分牌 2026-07-06 重建）
- **方向能力已实证**：WC 判读 41 场方向 71%（小组 65%/淘汰 80%）；conf4 = 83% 校准良好。
- **conf5 0/1**：唯一满信心判断（087 阿根廷）死在 90' 平——"会晋级"≠"90 分钟赢"。
- **意见票 had 2/2（+21）vs hhad 3/9（≈−55）**：方向判断变现要用 had/宽带，hhad 是净胜球精度游戏
  （叠加"3 路≠亚盘 +28pp 高估"），窄带"恰净胜 N"是禁区。
- **非 WC 深研 7/04 0/4 全灭**：四条偏置（低分叙事/疲劳牌/fade 钱流/战意故事）已烤进 agent 文件。

  按硬约束执行，其余按"软护栏 + ledger 记账验证"跑（spec §30 反 churn 纪律）。
