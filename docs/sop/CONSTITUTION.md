## 2. 判断的宪法（strength-v2，2026-09-26 Jun 批准改写；字典序，低序永不上溯）

1. **第一序·强弱天平**：每场的判断目标是**两队本场的最终强度对比**——双方真实强度（阵容/本场状态）、风格对位、战术剧本、**弱势方取胜路径是否成立（路径与强度）**、利好利空事件分级（事件、受益方、程度、是否已被价格吸收）。结论 = 方向 + 程度，落成 belief（事件分级 → pp）。**判断契约（2026-10-02 rubric r1）**：程度不再手写 pp——研究层对固定的类型化问题表逐项给「成立概率 + 来源」，pp＝项目上限×概率由代码派生；上限只许从逐项结账往下调或退役；事实层无一成立或均势→跟市场；把推断写成已确认的项被强制弃权。全文 RULEBOOK「九」。
   - 「机制活→盖住或丢整场」与死亡三证 3/3 **不再是出票前提**；活面集只作事实层记录（`faces_vs_alive`）。
2. **赔率是噪声识别器与情绪参考**，不是裁判：判断与价格一致 → 正常表达；不一致 → 必须回答「市场看到了什么我没看到」，查因后认定是情绪就坚持、认定是信息就修正。已被开盘→当前位移吸收的事件不重复计。
3. **第二序·P 定结构**：预算由纪律外生给定，帽内按**判断概率**最大化 P(全对)。**EV/每元效率禁入决策层**。
4. **第三序·奖池破平局**：奖池逻辑只在 P 不受影响处起作用（全包给判断 top1 最低场）。

推论：没有命名事件的场次跟市场；**拨动至少含一条官宣或确证结构级证据做锚，否则归零跟市场（2026-09-30 Jun 定：两天 16/16 表态面全对而拨动净负）**；含锚时小而真实的偏移如实表达（<5pp 不归零），`form_state` 每条 ≤1pp，多面位移峰值 ≤ 证据预算；单面封顶 10pp（有官宣 15pp）；**空仓永远合法**；高赔=高方差小额。

## 3. 两条元原则（本项目的全部方法论）

- **判断永不入脚本**：脚本只做取数、采集、确定性算术三件事；判读由主循环实时推理。
- **判据必须入代码**：散文规则挡不住"第五个更好的理由"（四票之死→audit 诞生；两次先例失效→C7 诞生）。凡是没被对象化的知识，都不参与执行。

## 6. 裁决协议（人性工程）

- **审票协议（2026-10-01）**：人出方案后机器跑 `betslip preview`，只有两条**否决**（有实证）：V1 期望回报率 < 0.5（中了也亏的 max-P 形状；足彩用奖金模型＝市场口径×判断溢价，不用全局中位数）、V2 与已购票共享裸单（假分散）；V3 倍投/重注只警告。否决＝改票后再审，不是机器替人下注；人坚持原票可以登记（登记是事实），但审票记录随票入账（`diagnosis.review`，2026-10-06 起真的写进票里；账房每月出「审票否决仍买」一行）。**理由先于结果**：偏离初稿的理由写于票内最早开球之后的，照记但不进「人的偏离」按理由的净值。否决表全文在 RULEBOOK「八」。

- 机器否决只拦**有正向实证的规则**（见 RULEBOOK「规则实证表」，2026-09-27 规则瘦身）：截至 2026-09-27 没有判断类规则达到实证，故无判断类 ERROR；WARN/INFO 只记账，**不要求逐条裁决**。审计门一组（`decision-audit-legs` 等）2026-10-13 删除，否决层只剩 `betslip preview` 的 V1/V2。票面结构＝帽内按判断概率最大化 P，保险给谁由 belief 算，不由旗或研究的结构建议定。
- 用户点名某腿 → 单独重审该腿证据，禁用组合 P 一票否决（r条4）。
- 分歧且无新证据 → 处方优先；用户否决审票（V1/V2）合法但须在登记时写 `--deviation` 理由，账房单列「审票否决仍买」（原 Adjudication 账随审计门 2026-10-13 删除）。
