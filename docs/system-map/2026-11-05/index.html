03 / THE HUMAN LOOP

追问、改判和提案，都能找到落点

① 在具体对象上问期 / 场 / 月账行 → 讨论流，应答员读取证据作答。
② 形成可核对记录纠正草稿记旧 → 新与证据；新规则进入待签提案。
③ Jun 确认 / 签字确认不等于已回写；签字不等于已执行。
④ 原入口执行并回挂改判 / 画像 / 账目各走权威入口，再标记结果。

买之前审，买之后记

CLI 与 Web 共用 precheck.py。结构否决为 V1 / V2；止损与注金帽另按资金纪律检查。真实购买在外部完成，登记只记录事实。

实验判决与规则上线分开

预登记 → 前瞻观察 → 结账 → 系统判决。展示类按登记出口分流；改变规则、码表或上限的提案进入待签，需人决定。
