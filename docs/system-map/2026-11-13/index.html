04 / THE HUMAN LOOP

追问、改判和提案，都能找到落点

① 在具体对象上问期 / 场 / 月账行 → 讨论流，应答员读取证据作答。
② 形成可核对记录纠正草稿记旧 → 新与证据；新规则进入待签提案。
③ Jun 确认 / 签字确认不等于已回写；签字不等于已执行。
④ 原入口执行并回挂改判 / 画像 / 账目各走权威入口，再标记结果。

买之前审，买之后记

CLI 与 Web 共用 precheck.py。结构否决为 V1 / V2；资金纪律另算：月度止损、期前定额、两张上限、中奖后不加码、降形价帽。白防线形与主形并排展示。真实购买在外部完成，登记只记录事实。

06 / RECOMMENDATIONS

先修四处，收缩十处，只在三个方向加码

判断层的结论已经稳定：机器的概率等于市场，研究标签挖不出信号。继续在这一层加功能，回报接近零。系统真正在产生价值的是三件事：把账记对、把坏结构拦下、把假设证伪。建议按这个标准取舍。

4先修：本周内，都是已发生的故障或敞口。
10砍与收缩：证据显示没有信号或无人使用。
