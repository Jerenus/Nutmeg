# Retro Football Manga v3 Style Bible

## Purpose

Retro Football Manga v3 is Nutmeg's global football-animation style system. It is not tied to one match, league, or real club. Daily match packs should inject the day's teams, tactical variables, and story beats into this fixed style system instead of reinventing the visual language.

## Core Creative Direction

Original 1980s retro youth-football manga animation with highly detailed hand-drawn line art, cel shading, paper grain, speed lines, dramatic close-ups, and serialized sports-anime storytelling.

The style should feel like a lost 1980s football comic adapted into animation:

- precise pen-and-ink linework with visible stroke-weight variation;
- cel-shaded color blocks, not glossy 3D rendering;
- old manga page texture, subtle film jitter, and analog broadcast warmth;
- intense but sincere youth-sports drama;
- football tactics shown through hand-drawn boards, freeze frames, and comic panels;
- recurring teams, recurring player archetypes, and episode-like continuity.

## Visual Anchors

Every generated segment should preserve these anchors:

- 2D hand-drawn animation, not 3D, not photorealistic, not modern mobile-game rendering.
- Fine black ink outlines with thicker contour lines and thinner inner detail lines.
- Cel shading with limited but rich color palettes.
- Manga motion language: speed lines, impact bursts, concentration lines, sweat drops, dust trails, panel gutters.
- Character faces: expressive, angular 1980s sports-manga faces; determined eyes; dramatic brows; no realistic celebrity likeness.
- Camera grammar: close-up eyes, boots hitting grass, ball spin, sideline boards, tactical overhead sketch, and dramatic low-angle shooting posture.
- Texture: slightly aged paper grain, faint halftone, subtle film gate weave, restrained scratches.

## Forbidden Direction

Avoid these outputs:

- direct imitation of any named IP, manga, anime, game, studio, artist, or character;
- real club crests, real player likenesses, copyrighted mascots, or exact kit reproductions;
- photorealistic football broadcast footage;
- modern glossy 3D animation, Pixar-like rendering, mobile-game gacha art, esports poster lighting;
- generic neon energy effects without hand-drawn manga structure;
- betting slips, odds boards, gambling terminals, money, tickets, or platform UI;
- random one-off character designs that break series continuity.

## Global Negative Prompt

Do not use real club logos, real player faces, real celebrity likenesses, copyrighted characters, named anime or manga IP, named game IP, photorealistic footage, 3D CGI, plastic skin, hyper-modern esports poster lighting, casino imagery, betting tickets, odds-platform UI, money, payment screens, or any gambling action.

## Team Abstraction Rule

Daily teams are converted into fictional anime teams. The fictional team may borrow broad color inspiration and tactical identity, but it must not reproduce real crests, exact kit patterns, sponsors, or official marks.

Examples:

- A Paris-based blue/red side can become `Paris Star XI` with star-and-tower abstract iconography.
- A Munich-based red/white side can become `Munich Red Thunder` with lightning-and-mountain abstract iconography.

## Continuity Rule

Each daily episode must keep:

- the same global drawing style;
- the same episode structure;
- persistent visual modules: opening title card, hand-drawn tactics board, simulated highlight, retro scoreboard, closing suspense card;
- fictional team names and character archetypes stored in a match-specific injection file;
- no final-match-result prediction displayed as fact.

## Match Analysis Boundary

Public animation scripts should explain football variables: pressure, transition, rest defense, first goal, set pieces, lineup risk, tempo, and tactical matchups.

Internal notes may include market observations, but public animation should not sound like a betting recommendation. Always include a responsible-viewing note in public scripts.
