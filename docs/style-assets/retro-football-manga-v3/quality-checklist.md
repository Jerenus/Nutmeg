# Retro Football Manga v3 Quality Checklist

Use this before approving a generated segment for publication or before generating remaining scenes.

## Style Fit

- [ ] Does it look like original 1980s youth-football manga animation?
- [ ] Does it show detailed hand-drawn line art and cel shading?
- [ ] Does it avoid modern 3D, photorealism, and esports poster lighting?
- [ ] Does it include manga motion language: speed lines, impact bursts, eye close-ups, paper grain, or panel structure?

## Continuity

- [ ] Are the fictional team colors consistent?
- [ ] Are player numbers, hairstyles, and roles consistent with the injection file?
- [ ] Does this scene feel connected to the previous scene?
- [ ] Does it preserve the episode's tactical theme?

## Football Relevance

- [ ] Does the scene visualize a real football variable from the analysis?
- [ ] Is the simulated highlight plausible for the tactical read?
- [ ] Are tactics shown clearly without overloading the screen?
- [ ] Does the closing question preserve uncertainty instead of claiming a result?

## Compliance

- [ ] No real club crest or official kit sponsor.
- [ ] No real player likeness or named celebrity.
- [ ] No named manga, anime, game, studio, artist, or character IP.
- [ ] No betting platform, odds slip, money, casino, or gambling action.
- [ ] Public script includes responsible-viewing disclaimer.

## Approval Rule

If any of the following fail, do not generate the remaining five segments yet:

- style fit;
- team continuity;
- no real crest/player/IP leakage;
- no gambling visuals;
- the segment actually feels like a scene from a continuous football episode.
