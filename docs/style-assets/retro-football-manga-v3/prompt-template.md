# Retro Football Manga v3 Prompt Template

## Prompt Assembly Order

Every video segment prompt should be assembled in this order:

1. Master style prompt
2. Continuity prompt
3. Fictional team injection
4. Character injection
5. Scene-specific action
6. Camera and animation notes
7. Safety and negative prompt

## Master Style Prompt

Original 1980s retro youth-football manga animation, highly detailed hand-drawn ink line art, visible pen stroke variation, cel-shaded color, aged manga paper grain, subtle film jitter, dramatic speed lines, impact bursts, sweat close-ups, intense youth-sports emotion, serialized football anime episode feeling, vertical 9:16 composition.

## Continuity Prompt

Keep the same fictional teams, kits, player numbers, hairstyles, and character roles across all scenes. The episode should feel like one continuous animated short, not unrelated posters. Use consistent manga line art, cel shading, and analog paper texture in every shot.

## Camera Direction Bank

- close-up on determined eyes, then snap zoom to boots touching the ball;
- low-angle shot from grass level, ball spinning through speed lines;
- manga panel split screen, two rivals running toward the same ball;
- hand-drawn overhead tactics board morphing into the live pitch;
- freeze-frame impact pose with ink burst and paper texture;
- old analog scoreboard flickers, then cuts to the next chapter card.

## Negative Prompt

No real club logos, no real player likeness, no official kit sponsor, no named anime or manga IP, no named game IP, no photorealism, no 3D CGI, no glossy esports poster lighting, no betting slips, no odds platform, no money, no casino visuals, no gambling action, no final-score certainty.
