# Retro Football Manga v3.1 Series Packaging

## Recurring Modules

Use these modules every day so the output feels like one continuing series.

### Opening Hook Card

- Duration: first 1-2 seconds.
- Visual: large face, spinning ball, scoreboard suspense, or comic-cover clash.
- Text: one short Chinese question.
- Rule: if the first frame is not understandable as a thumbnail, regenerate.

### Manga Cover / Tunnel Standoff

- Introduces two fictional teams.
- Shows team colors and abstract symbols without real logos.
- Uses old comic page texture and analog TV warmth.

### Weapon Card

- One team, one strength, one keyword.
- Use face/boots/ball close-up before tactical arrows.

### Counterweapon Card

- Opponent response to the first team's plan.
- Use split panels and collision of arrows.

### Tactical Notebook

- The analytical heart of the episode.
- Use notebook/chalkboard texture, not betting UI.
- 2-3 variables only.

### Simulated Replay

- One imagined highlight based on the tactical read.
- Must be framed as simulation, not a claimed future event.

### Retro Scoreboard Close

- The ending identity mark.
- Do not show final score certainty.
- Show a viewing question and the responsible-use subtitle.

## Series Memory

Persist these between segments and match-specific files:

- fictional team names;
- kit color families;
- character numbers and hairstyles;
- tactical identity labels;
- UI module order;
- ending disclaimer.
