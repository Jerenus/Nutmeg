# Retro Football Manga v3.1 Platform Output

## Douyin Output

Primary asset: 60-second 9:16 video.

Optimization factors:

- first-frame hook must be understandable without audio;
- first 2 seconds include a question or conflict;
- use large faces, large ball, large Chinese words;
- keep each scene visually different every 10-15 seconds;
- avoid dense tactical text;
- finish with a comment-driving viewing question.

Suggested title pattern:

- `这场欧冠，真正的变量不是强弱`
- `一分钟漫画拆局：谁先失去节奏？`
- `赛前战术动画：第一球可能改写全局`

## Xiaohongshu Output

Primary assets:

- same 60-second vertical video;
- one cover title;
- 3-5 tactical manga cards extracted from episode modules.

Card structure:

1. Cover: two fictional teams + match question.
2. Team A weapon.
3. Team B counterweapon.
4. Tactical notebook variables.
5. Responsible-viewing closing card.

Optimization factors:

- title needs search terms: `足球`, `欧冠`, `赛前分析`, `漫画`, `战术` when relevant;
- cards should be save-worthy, not only decorative;
- preserve no-betting and no-result-certainty wording.
