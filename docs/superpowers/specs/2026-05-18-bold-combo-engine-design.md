# 大胆组合引擎 — 设计文档

- **日期**：2026-05-18
- **状态**：设计待用户评审
- **一句话**：一个**娱乐性质**的竞彩串关组合生成器 —— 从盘面冲突 / 反直觉 / 热度里挑"大胆腿"，拼成有创意的 3/4/5 串 1。**不预测胜负、无 edge、长期负期望。**

---

## 0. 诚实声明（最重要 —— 焊死进产品）

2026-05-18 的 188 场 point-in-time 回测证明：预测模型(Dixon-Coles)打不赢博彩市场（46.8% vs 56.4%），冲突引擎无 edge。竞彩抽水约 **13%**。

**本引擎不是赚钱工具，是娱乐工具。** 用户在知情(听过上述事实)后选择构建它。它不预测胜负、不号称 edge、长期期望为负。每个输出顶部带硬标签，产品任何地方不得出现"胜率 / edge / 正期望 / 推荐加注"等暗示优势的措辞。

## 1. 背景

模型路线已证伪。预测模型 + 冲突引擎(模型 vs 市场) + 校准代码 —— 在本引擎路径上**整体退役、不被调用**（代码保留、测试在、无害，但不再是每日出方案的驱动）。每日出方案路径改为本引擎。

## 2. 它做什么

**输入**（无预测模型）：每场 = 体彩赔率（JCZQ `context.json`）+ 国际欧赔（`Fcom500OddsProvider`，现成）。

1. 每场每选项算一个**大胆分**（§3）。
2. 全天聚合出一个 **0-100 大盘面混乱值**，调制引擎抖动（§3.5）。
3. 每场选一条**大胆腿**，从"混沌池"生成**创意 3/4/5 串 1 组合**（§4）。
4. 输出 **1 张稳健底仓 + 一组大胆票** + 顶部硬标签 + 当天混乱值（§5）。

## 3. 大胆分（boldness score）

五个**真实盘面信号**合成（具名常量权重，可调）。它是**启发式显著性分，不是概率** —— 命名与展示一律叫"大胆分 / 冲突强度"，禁止叫"胜率 / 信心率"。

| 信号 | 含义 |
|---|---|
| **冲突分** | 体彩 implied prob 与 欧赔 implied prob 的分歧大小（你下注的体彩盘与更聪明的国际盘吵得越凶，越"有戏可挖"） |
| **反直觉分** | 该选项逆着体彩热门方向（`hot_direction`）→ 加分（反门 / 冷门 / 平局） |
| **热度分** | brief 第 1 节盘口标记（强胆场 / 舒服盘 / coinflip / draw_friendly / hi-vol）+ 体彩 vig 水位 |
| **漂移分** | 欧赔从初赔到即时赔率的移动幅度（500.com 欧赔页有初赔 + 即时）—— 市场改主意越多越"有戏" |
| **离散分** | ~29 家国际博彩公司彼此的赔率离散度 —— 专业盘越吵，这场越"混乱"（也是 §3.5 的零件） |

> 明确排除：球队战绩 / xG / H2H 等**预测类**输入 —— 那会把已退役的模型从后门请回。大胆引擎只吃盘面信号。

## 3.5 全天大盘面混乱值

每场由"离散分 + 冲突分"得一个**不确定度**；全天聚合（中位数）→ 一个 **0-100 的「大盘面混乱值」**。它做两件事：
- **显示在每个输出顶部**，作当天背景（平静 / 中等 / 混乱）。
- **调制引擎抖动**：混乱值高 → 候选池 `N` 变大、组合更长更野（更偏 4/5 串、反直觉权重上调）；混乱值低 → `N` 收敛、组合更短更克制。

## 4. 选腿 + 创意组合

- **选腿**：每场取大胆分最高的选项为该场"大胆腿"。
- **候选池 `N`**：不写死 —— 由 §3.5 的大盘面混乱值驱动（混乱日 `N` 大、平静日 `N` 小；上下界为具名常量，可调）。
- **组合**：从大胆腿池生成 3/4/5 串 1，按"合计赔率 × 平均大胆分"排序，输出靠前一组；混乱值高时向更长的串倾斜。
- 守 **Rule O**：每条腿不同场次、合法过关。

## 5. 输出

- **一张稳健底仓 + 一组大胆票。**
- **稳健底仓**：2-3 腿短串，取体彩最强热门（最低赔、最高隐含命中）。诚实标注 **"高命中倾向 ≠ +EV，同样在 13% 抽水内"** —— 它是大胆票的对冲压舱，不是"安全"也不是"+EV"。
- **大胆票**：每张 = 腿（场次 / 选项 / 体彩赔率 / 大胆理由）+ 合计赔率 + 平均大胆分。
- **每个输出(stdout / 文件 / PDF / bot)顶部焊死**：当天大盘面混乱值 + 硬标签：
  > 🎲 娱乐性质 · 非 edge · 长期约 −13% 抽水期望 · 仅用娱乐预算下注
- 注金：系统只标"建议小额娱乐预算"，不做任何"推荐加注 / 重仓"表述。
- 所有票**没有胜率 / EV 字段**（引擎没有概率）；复用 PDF 渲染时这些列显示"—"或省略，**不得编造**。

## 6. 落地

- 新服务 `nutmeg/services/jczq_bold_combos.py`。
- 新 CLI 命令 `jczq-bold-combos`（`--date` / `--write`）。
- 可复用既有 PDF 渲染 + Telegram 推送(`jczq_final_plan_pdf.py`)。
- 模型 / 冲突引擎 / 校准代码不删除，但每日默认出方案路径切到本引擎。

## 7. 验收

- 输出含 🎲 硬标签 —— 测试断言。
- 输出**不含** "胜率" / "edge" / "+EV" / "正期望" / "推荐下注" / "重仓" 等字样 —— 测试断言。
- 引擎用体彩赔率 + 欧赔，**不 import 任何预测模型**(`dixon_coles` / `ValueBoardService`) —— 测试断言。
- 生成 3/4/5 串 1，每张守 Rule O。
- TDD；全量 `uv run pytest tests/` 绿。

## 8. 范围外

- 不做胜负预测、不做模型校准。
- 不引入球队战绩 / xG / H2H 等预测类输入（§3 已明确排除）。
- 不号称有 edge、不承诺盈利。

## 9. 成功标准

一个**好玩、大胆、有创意**的串关生成器：从真实盘面信号(冲突/反直觉/热度)出发挑大胆腿、拼高赔组合 —— 同时**全程对自己是什么诚实**（焊死的硬标签、禁优势措辞、不报伪胜率）。它让用户的竞彩娱乐更有想象力，且不自欺。
