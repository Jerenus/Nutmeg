## 读法

1. **「市场/系统差异」有导向性，但方向是反的**：系统把热门砍 ≥5pp 的场，热门反而比市场更常开（+18.5 ±9.6）；砍 3–5pp 的场 ≈ 市场。与 26142 米兰 −14 / 26144 罗马 −7 / 26145 热门下拨 2/6 同一形状，与 F10（55–65 带热门低估 +16）同向。机制猜想：锚方 fail 几乎都已价内（priced_in True 189/208），rubric 的「已价内减半」不够，系统在市场已走完的方向上再走一遍。**用途是「别跟系统的大下拨」，不是买热门**（押热门 ROI@SP 历史 −10.9%）。
2. **研究判「均势」时，市场小热门很少赢**（19% vs 41%，n=26）：与规则 b「无机制 C 档当硬币先丢」同向，但这里说的是「丢」之外还有「弱方比市场更常开」——n=26，一格 2.8σ，可能是机会。
3. **洞在谁 / 洞单位 / priced_in / 死亡三证 / market_read / cover 面：没有一格超过 1.7σ**；cover 面残差 −1.2 ±3.4（n=163）是「翻车面没有形状」的第三次确认（前两次 n=90、n=42）。
4. ~~翻车面·标签（弱/真实）在竞彩研究 JSON 里不存在~~ **更正（2026-10-19 10:40）**：`underdog_path` 在契约里是 `strength_balance.underdog_path`（09-26 起），扫描器与构建器当时读的是顶层，所以误报「从未编码」。实际 09-26 后 375/375 份研究都有 `side`/`strength`（real 245 / weak 126 / strong 4），词典内 0 违规；side 与市场非热门一致 95.3%（n=277）。 原句：（`underdog_path` 字段 208/208 为空，标签是出包时从 `routes` 手工派生的），所以这一列**不可回测**；要测先进研究契约。
