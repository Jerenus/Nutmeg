# 实力模型前瞻检验（假期迭代 #6）· 2026-10-01

**问题**：`experiments/team_strength.py` 算的"每队相对市场的超额表现"（残差 = 实际积分 − 市场期望积分，收缩后）有没有预测力——两队累计残差之差能不能预测主胜相对 p(主胜) 的偏离？
**数据**：比赛表 1,472 场（jczq 1,305 / kernel 81 / zucai 86），2026-05-18 → 09-30；前瞻口径：每场只用开球前已完成的比赛算两队残差；两队各 ≥3 场历史 → n=367。
**命令**：`uv run python experiments/team_strength.py test --since 2026-07-01 --min-hist 3 --n-perm 1000`

| 样本 | n | 斜率（pp / 单位残差差） | 置换地板 95% | p |
|---|---|---|---|---|
| 全体 | 367 | −1.59 | [−5.84, +5.90] | 0.581 |
| 训练窗 | 183 | −2.76 | [−7.60, +8.52] | 0.496 |
| 测试窗 | 184 | −0.08 | [−8.78, +8.40] | 0.982 |

分桶：主队更超预期（差 > +0.3，n=126）主胜实际 40.5% vs 价格 45.2%（R=−4.7pp）；客队更超预期（差 < −0.3，n=139）主胜实际 39.6% vs 价格 43.0%（R=−3.4pp）——两头都是主胜略不如价格，**与因子方向无关**。

**结论**：null。球队"打得比价格好/差"的累计残差在前瞻样本上**没有**预测力（斜率符号还反了、p≈0.6、训练/测试窗一致）；两桶都是 −3 到 −5pp 的主胜整体校准差，不是因子效应。市场已经把近期超额表现定价进去了。**不再投入**：`team_strength` 继续作为 10:45 loop 的描述性产物，不进判断层、不进 belief；本体画像里"状态/近期表现"类的 pp 拨动在这个数据上没有根基（与 2026-09-30 `form_state ≤ 1pp` 的收紧一致）。
