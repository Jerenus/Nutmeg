# 样本养料：零样本 / 少样本实验的窗前历史样本（2026-10-05）

> 问题（Jun）：一些 0 样本的环节，历史样本能否作为训练样本？根据当时采集和判断的内容，整理样本养料，为完整过程做样本筹备。
> 工具：`experiments/training_pool.py`（复用各实验自己的结账适配器，不复制选样逻辑）；本文数字来自 2026-10-05 生产数据、修正去重后的语料（`evidence/2026-10-05-sample-ledger.md`）。

## 1. 结论

**能用，但只能做训练，不能做证据。** 历史样本可以做三件事：估计效应量与方差、验证结账适配器能跑通、排期和算功效。它们不能进判决，原因有二：这些假设本来就是看着同一批数据提出的（F10 登记时扫的就是这 400 行，F14 登记的理由就是 09-28/29 的 16/16）；而且大多数历史行没有前瞻证明（判读文件可改，只能算「声明在开球前」）。按 RSI 的规矩，重放结果进不了判决。

这次盘点最有用的不是历史读数本身，而是三件排期上的事：

1. **按登记的 n_min，几乎所有实验最可能的判决都是「跨线不判」（inconclusive）。** 即使历史效应是真的，到 n_min 时 F14 有 46%、F10 有 65%、F15 有 81% 的概率 CI 仍然跨线。要 80% 把握出判决，F14 需要约 112 行、F10 约 482、F15 约 654。证伪的概率在所有实验上都接近 0——这些判据是「要证明效应存在」，n_min 太小时结局通常是「没证明，也没否定」。
2. **F13 永远攒不到样本。** 它要求研究把 belief 从锚方拨低 ≥1.5pp，09-30 起拨动必须有官宣或结构证据作锚，这种拨动几乎不再发生：历史上整个 9 月只有 1 行，窗口内 0 行。
3. **K1 没有历史可用**（读者 A 的 rubric 答案 10-02 才开始有），前瞻也是 0——这是第 4 条的时序缺口，修好之前它不会动。

补充来源：

- **F14 的更早代理**：stance 契约（09-23）之前，足彩判读文件的 `call`（处方面，如 3 / 31 / 10）就是当时的结构表态。23 行，+11.7pp [−5.2, +27.1]，方向一致；全部 unproven。
- **F13 放宽口径**（只要锚方完整度 FAIL + 崩塌叙事，不要求拨动）：09-17 → 09-30 共 9 个比赛日 n=25，锚方实开比市场高 +20.6pp [+3.3, +36.6]，与画像③「崩塌故事越完整越不崩」同向。只「完整度 FAIL」一条：n=58，+11.6 [+0.6, +22.3]。这是看了两个口径之后的读数（variants_tried=2），只够登记，不够当证据。
- **预测账**（内核 `predictions`，08-27 → 09-26 登记 203 条可证伪预测）：已结 137 条，命中 84（61%）；**还有 60 条从未结账**（26115 ×6、26119 ×1、26124 ×23、26126 ×13、26131 ×17），对应的期早已开奖。这是现成的、带登记时间戳的判断样本，补结即可用。

## 3. 每个零样本环节怎么用这些养料

| 实验 | 养料够不够 | 建议 |
|---|---|---|
| F14（主指标） | 历史 64 行 proven、方向为正 | 作先验与功效依据：到 n=60 时 54% 成立、46% 跨线。第 8 条「F14 判决后的动作」必须写上跨线分支，否则最可能的结局没有预案。 |
| F10 / F15（热门带） | 历史效应为正且 CI 不含 0，但 n_min 太小 | 判决大概率跨线。若要一个能出结论的检验，需另立 n≈480 / 650 的实验（冻结字段不能改，只能另立）。钱口径看 G1，历史为负。 |
| F13 | 口径选不出样本 | 建议退役 F13，按放宽口径另立 F13b（Jun 决定）。 |
| K1 | 无历史 | 先修第 4 条的时序缺口。可选：让两个读者 B 各读一遍 260 份历史研究，测 B 对 B′ 的一致性，作为「问题表可读吗」的代理（要花 haiku 调用；不能替代 A 对 B）。 |
| G1 | 403 天回放已给出先验（为负） | 不需要更多历史；前瞻照常结账。 |
| F5 / F9 / F11 | 已在前瞻累计 | F9 要分出 0.4pp 的差需要 n≈1,500，按 n=60 设计不可能定论，已降为次指标是对的。F5 前瞻读数与登记方向相反（+14 vs −8）。F11 历史只有 17 行，无参考价值。 |

## 4. 复核

```bash
uv run python experiments/training_pool.py                      # 打印每个实验的窗前分档读数、日程、功效
uv run python experiments/training_pool.py --json /tmp/pool.json
```

功效与 `Falsifier.evaluate` 同口径：只看 CI 两端，上界低于门槛为证伪、下界不低于门槛为成立、否则跨线；CI 半宽按 1/√n 外推，假定历史点估计就是真效应。
