# 本场表现影响因子清单：可观察性、证据类别、现状读数

日期：2026-09-22
起因：Jun 问「一支队面对不同联赛/对手时的战意能否作为评判因子」「能否组合各种影响本场表现的因子来调整两队之间的天平」。
口径：宪法第二序（P 定结构）之上只允许命名因子偏移，且偏移要过 CLV 事前 + Brier 事后；本表按此把每个因子分到「已在价格内 / 结构层 / 情境层 / 只作复盘」。

## 2. 对「战意能否作因子」的回答

能，但只有在它被翻译成赛前可观察、赛后可判真假的代理之后。今天的清单里它已经有三个代理在语料里：弱点标签、轮换风险、休息天数；第四个代理「赛事优先级 / must-win」还只在散文里，建议进研究契约作枚举字段：
`incentive: {"home": "must_win|nothing_at_stake|priority_league|priority_cup|dead_rubber", "away": ...}`。
战意本身不进因子表：它不可观察、赛后可改写、且 07-04 实证三个战意故事场全灭。

## 3. 对「组合因子调整天平」的回答

数据说的是相反的事。带弱点标签的一方在 176 个观测里超价兑现 +11.6pp，锚方完整度 PASS 的锚方低于价格 −18.5pp。两者都不可区分于噪声，但方向一致地指向：**市场不仅定价了这些弱点，还常常过度定价**。所以"把两队因子加总去移动 310 概率"这条路，在现有 1,578 行上没有一条因子够格；能做的是宪法第一序的用法：因子决定面的活死与表达阶梯（盖住、降格、丢），不决定概率。

要让"天平"真的可调，条件是某个因子在严格前瞻档 n≥60、高于地板、分窗同号。现在最接近的是锚方完整度，而它的方向是反的。

## 4. 已落地

- 语料：研究 JSON 的 team_tags / tracking_tags / rotation_risk / rest_days / anchor_side 进 labels（88 行有标签，60 行有轮换风险）。
- 因子：`weakness_tag_side`、`hole_unpriced_side`、`anchor_side_integrity` 进 `factors.json` 为 probability 候选，每日闭环自动测。
- 未做：研究契约的 `incentive` 枚举（要改 intake 词典，走 probation）；`hole_location` 受控形态在 154 份历史研究里为 0，要从今天的研究开始积累。
