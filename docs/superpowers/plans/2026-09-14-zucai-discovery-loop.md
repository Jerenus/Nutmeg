# 足彩判断闭环实验设计 v0.1（Discovery Loop）

> 立档 2026-09-14。设计依据：用户提出的八个共同设计模式（Karpathy autoresearch /
> Discovery Loop / FutureHouse Robin / Darwin Gödel Machine / Finch / Lila / program.md）。
> 本文件是**设计与纪律**，不是可执行参数。可执行参数在 `experiments/policy-*.json`。

## 0. 地基（2026-09-14 实测，不可绕过）

| 事实 | 数值 | 含义 |
|---|---|---|
| 判读层几乎不动分布 | belief≠prior 仅 **12/306 = 3.9%** | 96% 场次照抄市场价 |
| 判读层 BSS vs 市场 | **+0.15%**，CI[-0.20, +0.55] | 与零无法区分 |
| 价格带权重样本外 | 训练 +0.96% → **测试 +0.28%**，CI[-1.31, +2.05] | 价格层无 edge |
| 市场基线残差 | **+4.4pp**（n=42，价格校正后） | 去水 fair 接近无偏 |

**推论**：edge 若存在，只可能在 (a) 私有标注层 (b) 表达层。价格层已排除。

## 1. 四层可证伪假设

| | 假设 | 证伪判据 | 状态 |
|---|---|---|---|
| H0 | 价格带特征有 edge | 样本外 BSS 的 95%CI 含 0 | ⚠️ 已部分证伪 |
| **H2** | 表达层存在系统性负 edge 且可修 | 各排面档 R_excl 的 CI 含 0 | ⛔ **已证伪(见 §11)** |
| H1 | 私有标注层有 edge | 标注特征加入后样本外 BSS ≤ H0 | 次优先 |
| H3 | edge 是 regime 条件化的 | 分 regime 的 BSS 方差 ≥ 合并方差 | 待 H1/H2 |

执行顺序由用户 2026-09-14 拍板：**H2 → 赔率位移先导 → H1 → H3**。

## 2. 评估函数（模式①）

三层决策 → 三个指标，不可混用。

1. **判读层** `BSS = 1 − Brier(policy) / Brier(去水fair)`
   零基线自带（市场价永远免费），BSS>0 直接等于有增量。已实现 `zucai_loop.py eval`。
2. **表达层** `R_excl = 实际开出率(被排面) − fair均值(被排面)`，按排面档分层
   （省钱≤15 / 灰带15-20 / 买方差>20 / 翻面=模态面）。零假设 R=0。
3. **票面层** 穷举反事实分位：每期枚举整个合法票面可行域，算我们实际出票在
   P(9/9) 分布中的分位。**把票面层样本量从「每期1」放大到「每期数千」。**

## 3. 一转（目标 ≤5 分钟）

```
propose → replay(训练窗) → validate(测试窗) → tournament(BTL) → archive → gate(人)
  30s        10s              10s               20s             5s
```
现状转速每周 2.3 转（每期 1 次）→ 目标每天 50 转。

**为什么要 BTL 而不只是比 BSS**：两个 policy 的 BSS 差异常在噪声内
（实测 CI 宽度 ±1.6% 而信号 +0.28%）。逐场配对比较消掉「板冷板热」的共同方差，
小样本下稳得多。

## 5. 档案 schema（模式④）

`experiments/archive/<regime>/<style>/<policy_id>.json`

- **regime**（赛前可判，用 Σtop1/14，不用赛果）：`cold` ≤5/14 · `neutral` 6-9 · `hot` ≥10
- **style**：`market`(纯跟市场，永久对照组) · `weighted` · `ontology` · `contrarian`(逆旗)

每槽留 BTL top-2 + 行为距离最远的 1 个（逐场 belief 的 L1 距离）。
**`market` 槽永不淘汰——它是零点，丢了就无法知道自己有没有 edge。**

## 6. Gate v2（2026-09-14 改版，v1 见 §14）

**闸分两类，不得合并成一个总分：**

| 类 | 成员 | 处理 |
|---|---|---|
| **有效性 / 权威** | 泄漏闸（BSS≤+5% 或过 ablation）· 人类闸（Adjudication 不否决） | ⛔ **硬 AND，不可加权** |
| **证据** | 非劣性 · 配对胜率 · BTL 名次 | ✅ 合成**方向分** 0-100 |

泄漏闸不能加权，因为**泄漏特征的 BSS 越高越糟**——高分正是症状，加权会把它当优点。
人类闸不能加权，因为那是行权，不是分数。

**证据分必须拆成两个数，不合并：**
- **方向分** direction (0-100)：样本若足够，这策略看上去有多好
- **信息量** information (0-100%)：本样本能支撑多少 = `|观测 BSS| / MDE80`

**部署条件**：硬闸全过 **AND** 方向分 ≥ 60 **AND** (信息量 ≥ 50% **OR** 用户显式行权)。

配额：每期只允许 **1 个**新参数进实盘，走 `rx.json` 预注册。
`experiments/attempts.log` 记尝试次数，显著性门槛随之抬高。

## 7. ⛔ 数据采集纪律（防泄漏）

| 类 | 例 | 泄漏风险 | 判决 |
|---|---|---|---|
| A 我们赛前自己写的 | reads.note / rx / judgment | 零 | ✅ 全力回填 |
| B 带赛前时间戳的档案 | 赔率多点快照（23 期） | 零 | ✅ 立刻接入 |
| C 赛后可查、赛前未记录 | 伤停名单、实际首发、战意 | 高 | ⛔ **禁用** |

**C 类不是拿不到，是拿到了也不能用。** 事后检索必然混入赛后报道，且检索者
已知谁最终上场，会制造虚假 edge。

**伤停/减员/战意的无泄漏代理 = 赔率位移**（23 期有 ≥2 赛前快照）。
位移已经是「市场加权后的重要性」，比原始伤停名单更好用。

### 泄漏自检硬规则
> **任何新特征加入后，若样本外 BSS 跳到 > +5%，先假定是泄漏，不是发现。**
> 依据：市场基线残差仅 +4.4pp。在接近有效的市场里 +5% 是异常值而非成就。
> 触发后强制 ablation：逐条核对特征取值的时间戳早于开球。

## 11. H2 实验结果（2026-09-14 首跑）

语料：26106-26123 全部票面文件，按「期×场×被排面」去重 → **291 条排面决策 / 18 期**。

```
档            n    fair均值   实际开出   R_excl    95%CI
买方差>20    159    25.5%    25.8%    +0.3pp   [-6.2, +7.0]
灰带15-20     56    17.9%     8.9%    -9.0pp   [-16.0, -0.3]
省钱≤15       62    10.2%     8.1%    -2.1pp   [-8.1, +5.0]
翻面(模态)     14    48.2%    42.9%    -5.3pp   [-29.0,+20.5]
★全体        291    21.9%    19.6%    -2.3pp   [-6.4, +2.3]
```
Bonferroni(α=0.0125, 4档) 校正后**无一档显著**。逐期分解 11/18 为负、7/18 为正，无单期驱动；
灰带样本散布于 15 期，最大单期占比 14%。

### 结论一：「被排面链」是幸存者偏差
全体 R_excl = -2.3pp，CI 含 0。**我们排掉的面总体开出率并不高于其 fair。**
记分牌上的「被排面七连/三连」来自只记得断腿的那几次。该链已标记 `falsified`。

### 结论二：零假设必须重构（本次实验最重要的产出）
> **R_excl = 0 不是「没问题」，而是「我们在这一档的排面判断等于抛硬币」。**

按此重读：
- **买方差>20 档 R=+0.3pp → 判断力为零**
- 灰带15-20 R=-9.0pp（点估计，校正后不显著）→ 可能有判断力
- 全体 → 零

### 结论三：C14 的机制要改写，结论保留
C14 原立论「>20% 的面更容易开」被数据否定（该档 R=+0.3pp）。
**正确立论：既然我们在该档没有判断力，排掉一个 25% 的面就是净损失 25% 命中率而零补偿。**
规则结论不变（">20% 不许排"），机制必须改写。同理 8/08 铁律「只丢场不降档」得到更强支持
——降档＝在无判断力的档位上买方差。

### 下一步
H2 的第二个指标（穷举反事实分位）未跑。但鉴于结论二，其预期结论已可预判：
若排面判断力为零，则我们的票在可行域 P(9/9) 分布中应落在中位数附近。
**优先级让位给 W1.5 赔率位移先导实验。**

## 13. W1.5 赔率位移先导实验（2026-09-14）

**目的**：用零成本的代理变量，决定要不要花一周回填 29 期标注。

语料：19 期有 ≥2 个赔率快照 → **264 场**（官方赛果串含 `*` 的取消场已剔除）。

### 检验1 · 晚盘是否优于早盘
```
早盘 Brier 0.5730 → 晚盘 0.5734    BSS = -0.07%   CI[-0.42, +0.28]   无法区分
```
**我们 18:30 的「临场位移复核」在概率层面没有产生价值。** 该流程环节可降级为只做事实核对
（停赛/改期/板面对齐），不再期待它改善判断。

### 检验2 · 位移在晚盘之外的增量（基线=晚盘）
```
k=-2.0 +0.08%   k=-1.0 +0.07%   k=+1.0 -0.14%   k=+2.0 -0.36%
最优 k=-1.5  BSS=+0.08%  CI[-0.44,+0.61]  不显著
```
方向上「反向(fade)」一律优于「动量」，但幅度全在噪声内。

### ⭐诊断：不是信息没用，是快照间隔太短
```
位移幅度  中位 0.5pp   90分位 2.0pp   最大 4.8pp   ≥3pp 仅占 2%
```
两个快照相隔 4-8 小时且**同日**，市场早已把消息price in。真正的位移发生在赛前 1-2 天
（伤停消息落地时），而**那段历史我们没有存下来**。

### ⭐根因：流水线原地覆盖写，自己抹掉了自己的历史
`ZucaiOddsSyncService.sync` 的文件名只由 slot 决定
（`{issue}-odds.json` / `{issue}-odds-revision.json`），同 slot 重复抓取即覆盖，
每期最多只剩 2 个同日快照。

**已修复（TDD）**：新增 append-only 存档 `snapshots/{issue}-odds-{captured_at}.json`，
规范文件仍是最新一份（既有读端零改动），`ZucaiOddsSyncResult` 新增 `archive_path`。
测试 `test_sync_archives_every_capture_append_only`。

### 结论：先导实验对 H1 **不作结论**（代理因机械原因失效），但给出两条可执行结果
1. 18:30 位移复核降级为事实核对
2. **从 26125 起把 prep 链的首个快照提前到 T-2/T-1**，约 10 期后即可获得真正的位移数据集，
   零标注成本。在此之前 **H1 标注回填不启动**。


## 14. 闸的功效缺陷与 v2 改版（2026-09-14）

用户提问：「四道闸全不过是不是存在优化的需求？不用约束逻辑而是权重判断？」

### 诊断：v1 的统计闸在本项目数据量上不可达
```
v1 统计闸 = 样本外 BSS 的 95%CI 下界 > 0
要让 +0.28% 的真实效应满足它 → n ≈ 5,514 场 ≈ 394 期 ≈ 2.5 年

功效分析 (n=154)：80% 功效最小可检出 BSS ≈ 2.93%，点估计仅 0.28% → 欠功效约 10 倍
配对检验也救不回：逐场 95%CI[-0.0105,+0.0077]，85胜69负，符号检验 p=0.227
```
**「❌统计闸」长期等价于「样本查不出来」，却被读成「策略不好」。这是真缺陷。**

### 但放松阈值是错的修法
把四道闸加权平均到"有东西能过"，等于把**分辨不出**洗成**看起来不错**——
正是 26105「叙述完整度≠概率」和 2026-09-13「锚方完整度 49pp 伪相关」同一个失败模式。
首版加权分给 BSS +0.22%（与市场无法区分）的策略打了 83/100，就是这个错误的现形。

### 改法：两类分离 + 功效折扣（见 §6）
实测效果——**contrarian 是唯一信息量过半的策略（56%），而它的方向分只有 25**：
```
排名 policy      style        BTL     BSS   配对胜率    p值  方向分  信息量   判定  硬闸 部署
1   e60b0c8965  weighted   +0.171  +0.22%  55.2%  0.227    83    8%  欠功效  ✅  ❌
2   dca016cd4e  weighted   +0.137  +0.28%  55.2%  0.227    78   12%  欠功效  ✅  ❌
4   eabc8d3fe2  market     -0.079  -0.00%  50.0%  1.000    10    0%  欠功效  ✅  ❌
5   c754564008  contrarian -0.226  -1.30%  42.9%  0.090    25   56%  欠功效  ✅  ❌
```
**样本唯一能说清楚的事，是「逆向策略是坏的」。** 这正是闭环的真实能力所在。

### ⭐由此重新定位闭环的主职能
```
确认一个 +0.3% 的效应 → 需要 2.5 年
排除一个 ≥2.9% 的效应 → 154 场就够
```
**证伪比确认便宜一个数量级。** 闭环两天的真实产出是杀掉四条规则
（被排面链 / 价格带权重 / 晚盘优势 / 位移动量），而不是选出更好的策略。
**主职能定为证伪机，选拔是副产品。** 路线图相应调整：优先设计"能被这个样本量杀死"的假设，
而不是"需要三年才能确认"的假设。


## 15. 假设批次 1（2026-09-14，证伪机首次批量运行）

### 三条结论
1. **旗族全线证伪（n=178）**。「旗指平→开平」R=-0.9pp、「方向旗→非模态」R=-2.3pp，
   两条都能排除 ≥9pp 的效应。此前只有 shield 9/40 的印象，现在有了正式力度。
2. **C6 精确复检证伪（n=130）**。其立论「降格场第3面开出频率高(26101 7场中5场)」
