# 26113 Rule Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish the 26113/26114 probation-rule implementation so audit vocabulary,
official Renjiu history, optimizer ranking, deployment selection, and the operator UI use
one deterministic contract.

**Architecture:** Extend the existing pure audit and arithmetic modules; do not add a new
service or persistence path. A fixed history-window constant and the existing official-row
validator are shared by CLI and product queries. Authored marker/fair/candidate inputs remain
the only source of football choices.

**Tech Stack:** Python 3.12+, dataclasses, Decimal, Typer, existing FastAPI product query
service, pytest, ruff, uv.
