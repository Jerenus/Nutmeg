# 决策本体 · M2 切换（新系统自立 + 下葬旧机器）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development，逐 task 派新 subagent + task 间审查。步骤用 `- [ ]`。

**Goal:** 让新决策系统**运营自立**（自己 fetch/出票/出报告/推送），把 6 个旧 launchd 定时任务全部切成新 decision 管线，删除 63 个闭包外旧分析模块 + 16 个旧 jczq-* CLI 命令。用户令：全删全切。

**Architecture:** 依赖分析确认新系统真正承重仅 11 个 services 模块（jczq, jczq_apifootball_odds, jczq_bold_markets, jczq_market_kernel, jczq_match_align, jczq_results, jczq_value_bridge, psychology.*, value）。其余 63 个 import 上可删，但其中 zucai_source/zucai_odds_source（抓 zucai 数据）、worldcup.report_pdf（PDF）、Telegram 客户端是**运营依赖**——删前必须在 decision 内补等价。故顺序：**先建自立能力 → 换任务 → 删旧码**。

**⚠️ 世界杯安全底线（不可违反）：** 今天 7/07，世界杯到 7/19，旧 `wc-report-20` 是 live 日报。**必须先把新 decision-report 建好、真机跑通推送成功，才允许删旧 wc-report 任务。** 任何一天不能断日报。

**Tech Stack:** Python 3.12 / pytest / uv。复用保留模块的 fetch 基元 + reportlab NutmegCJK 字体 + 共享 Telegram 客户端。

**纪律（每 Task）：** TDD；`uv run pytest tests/decision/<file> -q`；只碰列出文件；删除类 task 后必须 `uv run pytest -q` 全绿 + 新管线 e2e 冒烟；git 每 task 提交（可回滚）；结尾 `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`。
