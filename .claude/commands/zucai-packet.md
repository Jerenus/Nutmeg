## 章节（顺序就是他的阅读顺序，不要换）

**§0 头部一行**：停售时间、首场开球、各场首发大约几点出（开球前约 60 分）、本月净 / 止损余量 / 刹车状态、研究到齐 N/14、今天是热板还是冷板（≥80% 的场有几场）。

**§1 四类分层 + 人性面**。四档按**系统判断概率**切：强单 ≥80 ／ 稳双偏单 57–79 ／ 中间 45–56 ／ 硬币 <45。每场一行：市场 3/1/0、系统 3/1/0、面、信心、一句依据、一句风险；系统与市场差 ≥3pp 的场**单独点出差几个点**（判断层 Brier 历来不比市场好，偏离要可见）。人性面接在表后：Polymarket 成交额前五与 CR 线索（⚑ 只看不用）、哪几场是「完整的崩塌故事」（4 个样本的经验：越完整越不崩——**两边一致地用**，弱方的崩塌故事同样算）、哪几场是「名气与状况不符」。

**§2 28 队对本场对手的优劣势 + 翻车面**，按四类分开写。每队 2–3 条优势、2–3 条劣势，都要有研究原文来源。翻车面＝热门面之外最可能打死票面的结果：概率、路径强度（**真实 / 弱**）、具体剧本一句、赛前要看的信号（首发里谁）。硬币场没有翻车面，只写被排掉的那一面和它的概率。

**§3 完整度与损耗**。每场两队：中轴缺几个、国家队受伤**已确认缺阵**的人（点名）、带伤回归、周中有没有欧战/轮换风险、休息差。注明哪些已在价内、哪场系统因此改了概率（改了几个点）。泛化的「疲劳、长途」只当 0–1pp，F16 的预期就是证伪，不夸大。

**§4 状态 vs 实力（主队对客队）**。分三组：**同向**（状态与实力一致，单选依据最足）／**打架**（状态与市场方向相反，只配双选或全包）／**硬币**。每场一句数据层面的状态（xG、近 5 场）和比分层面的状态分开写——26137 霍芬海姆就是「数据好、比分差」。

**§5 双选决策**。只写中间档与硬币场：选哪两面、排掉哪面、被排面的系统概率、研究表态面与 cover、与市场差多少。两种放法差 <1pp 时明写「算术上是抛硬币」。

**§6 胆的候选**。分两种胆，目的不同，分开列：
- **结构胆**（省注数）：系统概率 ≥65% 且翻车面路径为「弱」的场，按**模态面占前两面之比**排序（p1/(p1+p2)：同样省一半注数，这个比值高的场单选、低的场双选，整票 P 更高——硬币场永远排最后，单选硬币从来不是买 P）。65–79% 档要写出翻车路径是真实还是弱，并标「中档胆」。门槛不设 80%：校准账（29 期）显示 60–80% 热门实际命中比市场高 6–8pp；26137 错在三票共享两条胆，不在门槛。
- **博胆**（买奖金，人性面）：硬币场或防平场里**人群在另一边**的面（CR 线索 fade/cover、Polymarket 扎堆、名气 vs 状况）——中了分得厚，这是单选一个 <50% 面的唯一正当理由；顺人群的硬币单选（26137 柏林联、勒沃库森都是模态面）既不买 P 也不买奖金，只能算「省注数的赌」，要明写。每张票最多 1 条博胆，**绝不跨票共享**，登记时 `--deviation price_instinct|fact_self_judged --prediction …`，进 Jun 的硬币自判账（26137 起：硬币场 4/5、大牌不胜 0/2，n 小）。
- 多张票若共享胆，写出胆同时成立的联合概率——那才是整组真正的 P。每张票的胆数与死点合计一行。

**§6b 胆选思路（思考层，Jun 自己定）**。机器不选胆，只把每一档「为什么能单选、代价是什么、人群在哪边」摊开，最后一列留空给 Jun。先一行写**本期奖金档位**：热板（≥80% 的场 ≥3）还是冷板——热板上正路全中的任九历史单注在 ¥200–2,000 一档（26134 9/9 只值 ¥217），冷板可到五位数（26136 ¥10,334）；**热板上没有非正路胆就拿不到奖金，这是 Jun 的出发点，机器按它展开**。然后按四档各写：

| 档 | 单选的理由 | 机器要摊开的东西 |
|---|---|---|
| 强单 ≥80 | 买 P（结构胆） | 弱方路径真实/弱；人群扎堆程度（PM 成交、CR2）→ 开出时奖金薄多少；首发要看谁 |
| 稳双偏单 65–79 | 买 P（中档胆） | 翻车路径；**自己能不能零封**（4 场没零封的队单选＝赌它多进一球）；校准账支持这一档；跨票不共享 |
| 中间 45–64 | **非正路胆的主战场** | 研究 face 与 cover 各是什么；人群站哪边（PM、CR 线索）；**被少买的那一面是否有真实路径**；单选代价 p1/(p1+p2)；一句「这一面开出时奖金为什么厚」 |
| 硬币 <45 | 只有逆人群面有理由 | 顺人群的模态面单选＝省注数的赌，明写；逆人群面写剧本（谁进球、怎么守住）；每票 ≤1 |

防平场单列一句：全国人群**多买平局**（γ −21%，未看过块复现），所以「平」作博胆不一定厚，**名气大热不胜**（CR2 fade）才是最厚的面。

**§6b-1 强单翻车风险解读（每个 ≥80% 的场一段，固定七项）**。单选大热的默认是对的，这段只回答「这一场为什么可能是那 10–20%」：
1. 翻车面与系统概率（平还是负，差几个点）。
2. 弱方的**固定招**与本季兑现次数（定位球、反击、低位锁死；26137 奥格斯堡定位球 4 场 11 球，我只给了 12% 平）。
3. 热门的**丢球端**：本季零封率与 xGA，不用「只丢 N 球」（拜仁「4 场只丢 2 球」是错前提，奥格斯堡当晚 xG 2.45）。
4. 热门**先丢球后的剧本**：本季落后次数、追回率、反超率（拜仁两次扳平未反超）。
5. 轮换与归队：周中欧战、国脚返程、带伤回归；首发几点出，看谁。
6. 人群与奖金：PM 成交、CR2 是否触发；热门开出时奖金薄多少 → 翻车面在票面上**盖的代价 vs 开出时的奖金**，一句算清。
7. 结论三选一：**单｜加面｜全包**，加「翻车榜位置」——翻车榜头部的热门历史上确实翻得多，榜尾≠安全（判读画像 2026-09-12）。

**§6b-2 稳双 / 中间的可生胆逻辑（每场一行判定，条件满足 k/n）**。胆不是选出来的，是条件凑出来的；凑不齐就写「不生胆」，不硬凑：
- **稳双 65–79 → 结构胆**，六个条件：①自己能零封（本季零封 ≥⅓ 场次或 xGA 低于联赛均值）②对手进攻 xG 真低（看 xG 不看比分，汉堡「两客场 0:7」不等于 xG 低）③翻车路径为「弱」且弱方无固定招 ④中轴齐、无欧战轮换 ⑤§4 里状态与实力**同向** ⑥本票其他票不共享此胆。≥5/6 机器默认「中档胆」，4/6 默认双选、标「可生胆但缺 X」，≤3/6 不生胆。
- **中间 45–64 → 非正路胆**，五个条件：①研究 face 与市场模态**不同**，或系统与市场差 ≥3pp ②人群站在另一边（PM 扎堆、CR fade/cover）③被少买的面有**真实路径**，剧本能点到人（谁进球、怎么守）④§4 里是状态与实力**打架**的场，且状态在被少买的一边 ⑤该面开出时奖金厚（名气大热不胜最厚；平局因全国人群多买平局不一定厚）。≥4/5 机器默认「非正路胆候选」，3/5 默认双选并写出差哪一条，≤2/5 不生胆。崩塌故事完整度反向用：对手的崩塌故事越完整，越不要押它崩。
- **硬币 <45**：不走生胆逻辑，只在 §6b 表里标「顺人群模态面＝省注数的赌」或「逆人群面＝博胆」。

输出一张表：场 / 档 / 候选面 / 理由类型（P 或 奖金）/ 路径强度 / 人群位置 / 单选代价 p1/(p1+p2) / **条件 k/n（§6b-2）** / 机器默认（单｜双｜全包）/ **Jun 的决定（空）**。Jun 填完的非正路胆按 §9 登记偏离与预测，进硬币自判账。

**§7 组合参考（算术，不是建议）**。胜负彩 ≤¥N 三版：A 帽内 P 最高 ／ B 处方忠实 ／ 刹车档；任九 R1–R4（我的版本、P 最高、刹车档、防最大名气场）。每张：票面、价、P(全对)、胆、丢场、与机器初稿的差。末尾「组合逻辑」四句：钱押在哪几条判断上、两两同死、至少中一张、这组本质上是一注什么。用 `betslip preview-set --plan` 算，不手算。进球彩只在 Jun 问时出，标「系统不支持，不入账」。

**§8（可选）进球彩**：crs 联合推进球分布，按预算给 max-P 结构；明写 off-ledger。

**§9 定案前**。Jun 的票面 → `betslip preview-set --plan`（至少中一张、同死、`--given` 钉住他明说害怕的那一场）→ 有明确害怕时先跑 `betslip complement` 看「在主单里修」与「外挂副单」哪个好 → 共享裸单逐条点名 → 首发复核的时间点 → `betslip register … --deviation … --prediction … --scheme-no …` 命令准备好。审票否决只记账，不拦登记。

**§10 赛后（retro）**。①赛果串与三源对账（官方未出写明「API-Football，待官方」）；②票面逐张：几对几、死在哪、事前 P；③翻车场逐场：赛前判断 → 场上事实（xG、事件、红牌、首发是否轮换）→ 判「结果打穿判断」还是「判断有错」，错在哪一条前提；④胆自评：每条胆单独评，共享胆的联合概率；⑤Jun 的自判逐条对账（他逆市场/逆研究的面各几对几，**n 小就说 n 小**）；⑥机器初稿与各参考版本会不会中（不存在「照机器打就中」时明写，防后见偏差）；⑦**不该学的部分**单列；⑧判断层 vs 市场 Brier；⑨记账：`retro encode --issue <期> --prize-per-note <官方单注>` → `scoreboard settle-issue … --no-dry-run --acknowledge-manual-source` → 复盘记忆 → 止损余量。

## 写法纪律

- 结论带 n；n 小就说 n 小，不用一期的赛果证明任何规律。
- 与 Jun 的判断冲突先说冲突，再给依据；不迎合，不因连亏改口。
- 机器不定票面：§7 是参考算术，票面由 Jun 出，审票在 §9。
- 每章节末一行数据来源与时间（研究 `captured_at`、赔率 `fetched_at`）；晚于开球的资讯不进判断。
- 回复末尾一行：`停售 HH:MM，剩余 N 分；首发出炉约 HH:MM`。最后 30 分钟每轮必报。
