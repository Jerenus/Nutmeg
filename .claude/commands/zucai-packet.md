**§2 胆与票**

## C 审票登记（§4）

Jun 的票面（截图＝真实下单）→ 逐场抄成点名式/位置式并核注数与金额 → `betslip preview-set --plan`（至少中一张、同死、死法清单、`--given` 钉住他明说害怕的那一场）→ 有明确害怕时先跑 `betslip complement`（搜出来的票已排除共享裸单与 ≥30% 共享排除面）→ 首发复核时间点 → `betslip register … --deviation … --prediction … --scheme-no …`。审票否决只记账，不拦登记；刹车超帽记「Jun 行权」。固定六查：
1. **薄胆点名**：每条 ≤55% 的单单独列联合概率——它们比博胆更常是隐形死因。
2. **每票博胆计数**：逆模态单选 + 排掉模态面的双选都算，>1 条明写「这张是 x% 的彩票」。
3. **同价换胆**：同注数下最弱的单改双、最强的双候选改单，先算再说。任九全包硬币是合法命中装置，不劝删。
4. **跨票同死**：共享裸单给同死 %，并给最小修改（哪张票哪一条改双、压到多少、多花多少）。
5. **关键位置变动问法**：门将/中卫换人先答被迫还是升级。
6. **跨票共享排除面**：V2 自动点名 ≥30% 的；任九里问「这场为什么不直接丢」。

## 写法纪律

- 结论带 n；n 小就说 n 小，不用一期的赛果证明任何规律。
- 与 Jun 的判断冲突先说冲突，再给依据；不迎合，不因连亏改口。
- 机器不定票面：§2 是参考算术，票面由 Jun 出；§3 是对照，不是第二轮方案。
- 每张表附数据来源与时间（研究 `captured_at`、赔率 `fetched_at`）；晚于开球的资讯不进判断。
- 回复末尾一行：`停售 HH:MM，剩余 N 分；首发出炉约 HH:MM`。最后 30 分钟每轮必报。
